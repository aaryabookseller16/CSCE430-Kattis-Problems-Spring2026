# Problem Set 3 Topics

Disjoint-set union, including a virtual-node trick for moving elements between sets.

## How to use this folder
Read `topic.md` first for the map, then open each problem folder. The main explanation is `solution.md`. If the folder has extra Python implementations, each has its own matching markdown file.

## Problem guide
- **Almost Union-Find** (`almost-union-find`): DSU with virtual nodes for move operations. Complexity: Almost O(alpha(n+m)) per operation; memory O(n+m).
- **Bridges and Tunnels** (`bridges-and-tunnels`): union-find with name compression. Complexity: O(n alpha(n)) time and O(n) memory.

## Main concepts covered
- DSU with virtual nodes for move operations
- union-find with name compression
