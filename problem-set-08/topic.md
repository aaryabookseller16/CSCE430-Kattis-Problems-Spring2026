# Problem Set 8 Topics

Graph traversal and dependency reasoning: bipartite coloring, topological sorting, BFS layers, and 0-1 BFS.

## How to use this folder
Read `topic.md` first for the map, then open each problem folder. The main explanation is `solution.md`. If the folder has extra Python implementations, each has its own matching markdown file.

## Problem guide
- **Breaking Bad** (`breaking-bad`): bipartite graph coloring. Complexity: O(N+M) time and memory.
- **Building Dependencies** (`building-dependencies`): reverse graph search and topological sort. Complexity: O(n+e) time and memory.
- **Chocolate Chip Fabrication** (`chocolate-chip-fabrication`): multi-source BFS by layers. Complexity: O(nm) time and memory.
- **Enchanted Maze** (`enchanted-maze`): No implemented primary solution. no implemented solution. Complexity: N/A for the checked-in file.
- **Jailbreak** (`jailbreak`): 0-1 BFS from three starting points. Complexity: O(hw) per BFS, so O(hw) overall per case; memory O(hw).
