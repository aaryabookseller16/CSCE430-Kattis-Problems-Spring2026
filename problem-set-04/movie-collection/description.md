# Movie Collection

You have a stack of movies labeled `1..R` (movie 1 on top). For each of `M` queries, given a movie id `x`, output how many movies are above `x`, then move `x` to the top of the stack.

## Input
`T` test cases. For each:  
`R M`  
`M` lines each with movie id `x`.

## Output
For each query, print the number of movies above the requested one.
