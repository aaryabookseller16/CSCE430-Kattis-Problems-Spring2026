# Problem Set 10 Topics

Strong connectivity and graph augmentation, including SCCs and condensation-graph reasoning.

## How to use this folder
Read `topic.md` first for the map, then open each problem folder. The main explanation is `solution.md`. If the folder has extra Python implementations, each has its own matching markdown file.

## Problem guide
- **Cantina of Babel** (`a`): strongly connected components. Complexity: O(N^2 + E) time because all pairs of people are checked; memory O(N^2) in the worst case.
- **Strong Connectivity Augmentation** (`d`): SCC condensation graph. Complexity: O(n+m) time and memory per test case.

## Main concepts covered
- strongly connected components
- SCC condensation graph
