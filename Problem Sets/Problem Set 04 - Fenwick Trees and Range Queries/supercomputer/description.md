# Supercomputer

Maintain an array of `N` bits (all start at 0) and support `K` queries:
- `F i` flips bit `i`.
- `C l r` prints the number of 1-bits in the range `[l, r]`.

## Input
`N K`  
Then `K` lines, each either `F i` or `C l r`.

## Output
For every `C` query, output the count on its own line.
