# Lab 4 Topics

Short implementation exercises: sequence formulas, simple geometry/physics observations, string scans, rank simulation, and prefix checks.

## How to use this folder
Read `topic.md` first for the map, then open each problem folder. The main explanation is `solution.md`. If the folder has extra Python implementations, each has its own matching markdown file.

## Problem guide
- **A Rational Sequence** (`a-rational-sequence`): Calkin-Wilf next-fraction formula. Complexity: O(1) per test case; memory O(1).
- **Ants** (`ants`): min/max fall time observation. Complexity: O(a) per test case; memory O(1).
- **Beekeeper** (`beekeeper`): string scanning. Complexity: O(total characters) per case; memory O(1) besides input tokens.
- **Game Rank** (`gamerank`): state simulation. Complexity: O(number of games) time and O(1) memory.
- **Oval Watch** (`oval-watch`): No implemented primary solution. no implemented solution. Complexity: N/A for the checked-in file.
- **Phone List** (`phone-list`): sorting and prefix check. Complexity: O(n log n + total digits) time and O(n) memory.
