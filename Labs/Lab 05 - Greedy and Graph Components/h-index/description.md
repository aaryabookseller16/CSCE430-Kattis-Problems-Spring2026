# H-Index

Given `n` papers with `c_i` citations, the H-index is the largest `H` such that at least `H` papers have `c_i >= H`.

## Input
- Integer `n` (`1 <= n <= 100000`)
- `n` lines: citation counts `c` (`0 <= c <= 1e9`)

## Output
Print the H-index.

## Sample
Input  
```
5
7
1
2
1
5
```
Output  
```
2
```
