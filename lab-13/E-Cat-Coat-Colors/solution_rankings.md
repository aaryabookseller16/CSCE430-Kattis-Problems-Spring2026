# Solution Rankings

1. `solution.py`
   - Method: build parent genotype choices from the input colors, then enumerate gametes and kitten sex
   - Time: constant for this fixed set of genes and colors
   - Best file to submit because it is direct and less compressed

2. `solution_table.py`
   - Method: same enumeration, but with more pre-expanded genotype tables
   - Time: also constant
   - A little shorter in places, but easier to make mistakes while editing
