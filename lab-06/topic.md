# Lab 6 Topics

Greedy trading, parity/case analysis, difference-of-squares math, and tree queries with Euler tour plus Fenwick tree.

## How to use this folder
Read `topic.md` first for the map, then open each problem folder. The main explanation is `solution.md`. If the folder has extra Python implementations, each has its own matching markdown file.

## Problem guide
- **Climbing Stairs** (`climbing-stairs`): small case analysis with parity adjustment. Complexity: O(1) time and memory.
- **Daydreaming Stockbroker** (`daydreaming-stockbrocker`): greedy stock trading with known future prices. Complexity: O(n) time and O(1) memory.
- **Falling Mugs** (`falling-mugs`): difference of squares search. Complexity: O(D) in the simple bound used; memory O(1).
- **Performance Review** (`performance-review`): Euler tour plus Fenwick tree sorted by rank. Complexity: O(n log n) time and O(n) memory.

## Main concepts covered
- small case analysis with parity adjustment
- greedy stock trading with known future prices
- difference of squares search
- Euler tour plus Fenwick tree sorted by rank
