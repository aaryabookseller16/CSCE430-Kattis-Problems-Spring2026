# Lab 10 Topics

BFS, Dijkstra, dynamic programming, direct simulation, and small mathematical case analysis.

## How to use this folder
Read `topic.md` first for the map, then open each problem folder. The main explanation is `solution.md`. If the folder has extra Python implementations, each has its own matching markdown file.

## Problem guide
- **Cow Crane** (`cow-crane`): case analysis on two delivery orders. Complexity: O(1) time and memory.
- **Fire!** (`fire!`): BFS simulation of Joe and spreading fire. Complexity: O(RC) time and memory.
- **Haiku** (`haiku`): word-break dynamic programming with syllable counts. Complexity: O(total line length * matching syllables) time; memory O(line length).
- **Mr. Plow King** (`mr-plow-king`): combinatorial greedy counting. Complexity: O(n) time and O(1) memory.
- **Semafori** (`semafori`): timeline simulation. Complexity: O(N) time and O(1) memory.
- **Stop Counting** (`stop-counting`): best prefix or suffix average. Complexity: O(N) time and O(1) memory.
- **Texas Summers** (`texas-summers`): dense Dijkstra shortest path. Complexity: O(n^2) time and O(n) memory.
- **Where's My Internet** (`wheres-my-internet`): DFS connectivity. Complexity: O(N+M) time and memory.
